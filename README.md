Turn your Android device into a **versatile wireless screen transmitter or receiver**.  
This application allows you to send your phone's screen to any device on the local network (PC, browser), or view the screen from another device.

⚠️ **Note:** WiFi Screen Streaming is currently in **BETA**. Features may be incomplete or subject to change.

---

## 📸 Overview  

*Work in progress. Screenshots coming soon!*

---

## ✨ Key Features  

* **Screen Sharing**: Stream your device's screen to other devices on the local network.
* **Low Latency**: Designed for fast and responsive screen mirroring.
* **Modern Interface**: Built with Jetpack Compose and Material 3 guidelines.

## 🛠️ Building from Source  

Open the project with [Android Studio](https://developer.android.com/studio?hl=en), sync the Gradle dependencies, and run.

```bash
./gradlew assembleDebug
```
